# Границы и швы

## Границы, решённые в спецификации

Одна граница — весь контактный блок.

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `ContactBlock` | телефон, ссылки MAX и ВК, подписи кнопок, порядок и вид | `ContactBlock()` — ноль аргументов, без пропсов | тексты и ссылки внутри; ни один другой файл не должен их дублировать |
| `RightsFooter` | прежний текст подвала с исправленным номером | `RightsFooter()` — ноль аргументов, без пропсов | — |

**Швы для тестов (единственные, проверяется только здесь):**
SSR отрендеренной главной — `GET /` содержит `tel:+79226802439`,
`https://vk.ru/id153803202` и ссылку-приглашение MAX целиком;
`GET /mission` содержит новый номер, но **не** содержит `max.ru`.
Тестовых хуков, экспортов и модулей ради тестов не вводится.

Константа телефона объявляется один раз в модуле блока и импортируется
`RightsFooter` — иначе правка одного номера разъедется.

## Правила проекта, которые нельзя вывести из кода

**Стек:** Next.js 16 App Router, React, TypeScript, Tailwind, framer-motion.
Всё в `frontend/`. Этот Next — не тот, что в учебниках: перед кодом прочитать
`frontend/node_modules/next/dist/docs/` (правило из `frontend/AGENTS.md`).

**Команды (из корня репозитория):**

```bash
cd frontend && npx tsc --noEmit   # типы, 0 ошибок — обязательно
cd frontend && npm run build      # прод-сборка next build — обязательно
cd frontend && npm run lint       # eslint
```

**Что нельзя трогать:** `frontend/src/server/**`, `frontend/src/app/api/**`,
`.zscripts/`, `content/**` без задачи. **Новая зависимость = `BLOCKED`** —
сообщить и остановиться, а не установить.

**Клиентские ссылки дословны.** Обе ссылки из брифа копируются символ в символ,
включая `_` и `-`. Обрезанная или «поправленная» ссылка ведёт в никуда.

**Секреты:** не запрашивать, не писать в файлы. Телефон и ссылки Ирины — не
секреты, это публичные контакты, которые она сама просила выставить.

## Что построено (прогон 2026-10-02, T0 — один проход)

- `frontend/src/components/ContactBlock.tsx` — блок «Купить карту и связаться».
  Выставляет: `CONTACT_PHONE` («+7 922 680 24 39»), `CONTACT_PHONE_TEL`
  («tel:+79226802439»), `VK_URL`, `MAX_URL`. Рендерит три ссылки — позвонить,
  MAX, ВК — с подписью блока, дословно закрывающей R03/R04/R05.
- `frontend/src/components/RightsFooter.tsx` — телефон теперь импортируется из
  `ContactBlock`, а не захардкожен. **Правка номера делается в одном месте.**
- `frontend/src/app/page.tsx` — `<ContactBlock />` между «Начать играть» и
  «Что тебя ждёт».

**Тестового раннера в репозитории нет** (ни jest, ни vitest; новая зависимость
запрещена), поэтому шов проверяется так: `npm run build`, затем
`npx next start -p <порт>` и `curl` по `/` и `/mission`. Это и есть проверка
через публичную границу — отрендеренную страницу.
